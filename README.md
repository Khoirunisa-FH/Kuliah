| Topologi | Karakteristik            | Keuntungan                      | Kekurangan                  |
|----------|--------------------------|---------------------------------|-----------------------------|
| Bus      | Single cable backbone    | Sederhana, ekonomis             | Single point of failure     |
| Star     | Central hub/switch       | Easy management, fault isolation| Central device dependency   |
| Ring     | Circular connection      | No collision, equal access      | Difficult troubleshooting  |
| Mesh     | Multiple connections     | High redundancy, reliability    | Complex, expensive          |
| Hybrid   | Combination of topologies| Flexible, scalable              | Complex design              |
